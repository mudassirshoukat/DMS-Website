A file is checked before anyone works with it

See every state a file can show

Every upload, and every new version, goes through a security scan first. Only a file that passes is processed. A file the scan blocks never is, and its page says what to do next.

  1. Upload, from the upload form or a watched folder.
  2. Security scan: Waiting for scan, Scanning, then Scan passed.
  3. Processing, then Processed.
  4. Or the scan ends at Blocked by the scan, and the version is Not processed.

Every version stays on the record

How versions work

Upload a corrected file and it becomes the current version. The earlier ones stay listed with who uploaded them, when, and the change note that says why.

Who adds a version

An Org Admin, or the Document Manager who owns the document.

Only real changes

A file identical to the current version is refused, so the history shows real changes.

One document, not two

Send the same upload again after a dropped connection and you still get one document.

A workspace for each organization

See who does what

Each person has a role in a workspace, and can hold a different role in another. Client and vendor contacts see only the exact versions shared with their company.

Roles in the workspace

Org Admin, Document Manager and Member, set by the workspace's Org Admin.

Sharing with clients and vendors

An Org Admin, or the Document Manager who owns it, shares one exact version with a company.
